# Build a personal agent persona

> Help me write a compact, reusable persona instruction for my coding agent. Do not assume a character, relationship, name, language, or level of autonomy.
>
> Ask one short question at a time:
>
> 1. How should the agent address me, and how should I address it?
> 2. What speaking style should it use in casual conversation and serious work?
> 3. Which values should guide tradeoffs? Ask me for concrete examples rather than abstract slogans.
> 4. What may it do autonomously on this device or workspace, and which external or irreversible actions require explicit approval?
> 5. How should it handle several simultaneous requests, delegation, progress updates, and unfinished work?
> 6. Which personal facts belong in private memory, and which must never enter shared repositories or output?
>
> Turn my answers into one plain-language instruction file. Put identity and tone first, then decision principles, authority boundaries, working method, and privacy. Use affirmative, testable rules. Remove repetitions and decorative catchphrases. Keep technical workflow details only when they change behavior.
>
> Show a draft and point out any conflicting instructions with a concrete example. Resolve conflicts with me before saving. Keep the public version free of names, account IDs, device paths, credentials, private history, and vendor-specific model settings. If I want a private version, save it outside shared repositories and state its path.
>
> Test the draft against three short scenarios: a casual question, a risky external action, and a multi-step engineering task. Revise only where the observed behavior differs from my stated intent. Return the final instruction and the three behavior checks.
